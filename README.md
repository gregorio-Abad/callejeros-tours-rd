# Callejeros Tours RD

Sitio web oficial de **Callejeros Tours RD**, empresa de excursiones y servicios turísticos en República Dominicana.

## Descripción

Proyecto web desarrollado con HTML5, CSS3 y JavaScript, enfocado en ofrecer una experiencia rápida, responsive y fácil de utilizar para consultar excursiones, conocer servicios y contactar al equipo de Callejeros Tours RD.

El sitio se encuentra publicado en producción y continúa evolucionando con nuevas funcionalidades.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Responsive Design
- Mobile First
- Flexbox
- CSS Grid
- Netlify
- Cloudflare
- Google Search Console
- WhatsApp Business
- WebP
- Git / GitHub

## Funcionalidades principales

- Catálogo de excursiones.
- Tarjetas con información, precios y detalles.
- Modal de información de excursiones.
- Galerías de imágenes.
- Diseño responsive para móvil, tablet y escritorio.
- Integración con WhatsApp Business.
- Sección de tours privados.
- Servicios de vehículos privados.
- Infraestructura bilingüe español / inglés.
- SEO técnico básico.
- Sitemap XML.
- robots.txt.
- Optimización de imágenes.
- Favicon y Web Manifest.
- Publicación con Netlify.
- DNS administrado con Cloudflare.
- Integración con Google Search Console.
