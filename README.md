# Callejeros Tours RD — Landing Page

Landing page estática, Mobile First y sin frameworks.

## Estructura

- `index.html` — estructura, SEO básico, accesibilidad y contenido.
- `css/styles.css` — estilos responsive con Flexbox y CSS Grid.
- `js/app.js` — catálogo de excursiones, modal de detalles, políticas y enlaces de reserva.
- `assets/` — espacio para logo e imágenes propias.

## Publicación

Puedes subir la carpeta completa a cualquier hosting estático compatible con HTML/CSS/JS (por ejemplo, tu hosting, GitHub Pages, Netlify o Vercel).

## Personalización rápida

Edita el arreglo `tours` en `js/app.js` para cambiar:
- fechas
- precios
- destinos
- descripción
- incluidos/no incluidos
- políticas

En `index.html` puedes cambiar textos generales, redes sociales y el contenido del panel de ofertas.

## Importante

Las políticas incluidas son una base de funcionamiento para la interfaz. Antes de publicar condiciones comerciales definitivas, reemplázalas por las políticas reales de Callejeros Tours RD y verifica que sean consistentes con tu operación y obligaciones legales.
